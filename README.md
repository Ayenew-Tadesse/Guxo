# Guxo

A UI/UX portfolio prototype: a full-featured intercity bus booking mobile app for Ethiopia, built as a single self-contained HTML file (vanilla JS, no frameworks). Built as a structural sibling to [Guxo Flights](https://github.com/Ayenew-Tadesse/hid-go), retheming the same interaction patterns around a fictional bus operator, "Guxo Line."

## Features

- Sign up / log in with persisted account data
- Round-trip and one-way bus search across major Ethiopian cities
- Results list with fare comparison, filters, and date-strip pricing
- Fare tier selection (Standard / Comfort / VIP) and a 2+2 seat map picker
- Payment flow (Telebirr, CBE Birr, cards) with a mock confirmation
- Trip management, ticket check-in, e-ticket, notifications, and profile screens
- Light/dark theme support and a responsive layout from phone to large desktop widths
- An original inline-SVG hero illustration (no stock photography or third-party logos)

## Stack

Plain HTML, CSS, and JavaScript — no build step, no dependencies. Open `index.html` in a browser to run it.
